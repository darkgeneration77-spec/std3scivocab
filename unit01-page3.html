看同一个实验情境，学会判断怎样答

先看图，再判断题目到底要你写观察、比较与测量、推断，还是预测。重点不是背答案，而是认出题目在问什么。

1. 观察

只写真正看到、听到或测量到的现象，不要偷偷加入原因。

答题路线：看见什么 → 写事实。

2. 比较与测量

使用适合的工具取得数值，再比较两个对象的差异。

答题路线：工具 → 数值 → 单位 → 比较。

3. 推断

事情已经发生，根据观察到的资料写出合理原因。

看到“为什么 / 解释”：观察结果 → 合理原因。

4. 预测

根据已有资料判断接下来可能发生的情况。

看到“接下来 / 预测”：已有资料 → 未来情况。
题目关键词 → 正确答法
观察

写实际现象，例如：植物的叶子下垂。

测量与应用数字

写工具、数值和正确单位，例如：高度是 15 cm。

推断

写合理原因，例如：植物可能缺水。

预测

写接下来可能发生的情况，例如：植物可能继续枯萎。

最重要的区别：
观察 = 发生了什么。
推断 = 为什么会这样。
预测 = 接下来可能怎样。

科学操作技能题也要会

正确使用 / 处理按正确方法使用科学器材、材料和标本，并注意安全。
绘画 / 记录按观察到的形状和特征画出标本、器材或材料，并清楚记录资料。
清洗 / 储存活动后清洗器材，并把器材和材料放回正确位置。

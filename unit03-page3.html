题目关键词：先判断问哪一块

本单元题目主要落在牙齿、食物类别、均衡饮食和消化。看到关键词后先确定对象，再写准确答案。

牙齿名称 / 功能

门牙＝切断；犬齿＝撕裂；臼齿＝磨碎。

牙齿结构

牙釉质、牙本质、神经、血管、牙龈。看到牙齿剖面图要能认出结构。

乳牙 vs 恒牙

比较出现时间、是否脱落和长期使用。

牙齿护理

刷牙、使用牙线、定期牙科检查。

食物类别

碳水化合物、蛋白质、脂肪、维生素、矿物质、膳食纤维、水。

食物功能

能量、生长修复、保温、健康、排便、调节体温等，要和食物类别配对。

均衡饮食

不是“吃很多”，而是适量摄取不同类别的食物。

食物金字塔

根据不同层级判断食物摄取比例，不代表每一种食物吃一样多。

消化定义

食物被分解成更小的部分，使营养更容易被身体吸收。

消化路线

口腔 → 食道 → 胃 → 肠 → 肛门。

题目 → 思考 → 答案

1. 哪一种牙齿主要用来撕裂食物？
思考：问牙齿功能。
答案：犬齿。
2. 哪一类食物主要帮助身体生长与修复？
思考：问食物类别与功能。
答案：蛋白质。
3. 为什么膳食纤维重要？
思考：问功能，不是食物例子。
答案：帮助排便并预防便秘。
4. 什么是消化？
思考：要写“变小 + 方便吸收”。
答案：消化是把食物分解成更小的部分，使营养更容易被身体吸收。
5. 排列食物经过消化道的路线。
思考：按器官顺序。
答案：口腔 → 食道 → 胃 → 肠 → 肛门。

题目关键词：看到问法，就知道答什么

这一页把牙齿、饮食和消化接到常见考试问法。重点不是背一整段，而是先找到题目要的“对象”。

问法 01

说出牙齿种类和功能

先写牙齿名称，再写它如何处理食物。

门牙＝切断；犬齿＝撕裂；臼齿＝磨碎
问法 02

比较乳牙和恒牙

从出现时间、数量和是否会脱落来比较。

乳牙较早出现并会脱落；恒牙之后长出并长期使用
问法 03

为什么要保护牙齿？

答案要连接“保持牙齿健康”和“帮助处理食物”。

关键词：健康、咀嚼、长期使用
问法 04

什么是均衡饮食？

不是“吃很多”，而是适量摄取不同类别的食物。

关键词：不同类别 + 适量
问法 05

排列消化过程

看到“顺序”“路线”“先后”，就要写器官次序。

口腔 → 食道 → 胃 → 肠 → 肛门
问法 06

为什么需要营养？

答案连接身体生长、活动和保持健康。

关键词：生长、能量、健康

题目 → 思考 → 答案

1. 哪一种牙齿主要用来撕裂食物？
思考：题目问牙齿功能。
答案：犬齿。
2. 写出门牙和臼齿功能的不同。
思考：比较两个功能，不要只写其中一个。
答案：门牙用来切断食物，臼齿用来磨碎食物。
3. 为什么儿童的恒牙需要好好保护？
思考：恒牙需要长期使用。
答案：因为恒牙需要长期使用，因此要保持恒牙健康。
4. 什么是均衡饮食？
思考：重点是“不同类别”和“适量”。
答案：适量摄取不同类别的食物，使身体获得所需营养。
不要写“均衡饮食就是吃很多健康食物”。“吃很多”不是重点。
5. 排列食物经过消化道的路线。
思考：写器官顺序。
答案：口腔 → 食道 → 胃 → 肠 → 肛门。

一眼判断答案方向

门牙切断
犬齿撕裂
臼齿磨碎
均衡饮食不同类别 + 适量
消化按顺序写路线
答题口诀：先圈“牙齿 / 饮食 / 消化” → 看题目是问名称、功能、比较、原因还是顺序 → 再写对应关键词。

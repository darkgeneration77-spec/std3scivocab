看图学科学技能

不要先背定义。先看“人在做什么”，再判断使用了哪一种科学技能。
观察资料 → 比较 / 分类 / 测量 → 推断 → 预测 → 沟通
👁️ 👂 👃 ✋

1. 五感观察

用眼睛、耳朵、鼻子、舌头和皮肤收集物体的特征和资料。

看到 / 听到 / 闻到 / 尝到 / 摸到 → 观察
🍃 🍂　● ▲ ■

2. 比较与分类

先找相同点和不同点，再根据共同特征把物体分成不同组。

找特征 → 比较 → 分类
📏 ⚖️ 🧪

3. 测量与应用数字

选择适合的测量工具，读取数值，并使用正确的标准单位记录结果。

工具 → 数值 → 标准单位
🌱 → 🤔

4. 推断

已经观察到一个现象，再根据资料想一想它发生的可能原因。

已经发生 → 为什么？ → 推断
☁️ ☁️ → 🌧️

5. 预测

根据已有资料，推测接下来可能发生的事情。

已有资料 → 接下来怎样？ → 预测
🗣️ ✏️ 📋

6. 沟通与记录

把观察结果通过口头表达、文字、绘画或表格记录，并与别人分享。

观察结果 → 记录 → 沟通
🥽 🧪 ✓

7. 正确操作科学器材

选择适合的科学器材和材料，依照正确步骤，小心处理标本并安全操作。

选择 → 正确使用 → 小心操作
✏️ → 🧪 → 🚿 → 🗄️

8. 科学操作完整流程

需要时绘画或记录，完成活动后清洗器材，再把器材和材料正确储存。

绘画 / 记录 → 使用 → 清洗 → 储存
最容易混淆：推断 vs 预测
推断：事情已经发生，我要解释为什么。
预测：根据现在的资料，我要判断接下来可能怎样。
